开场 · 定位

今天讲什么

约 30 秒

口播

今天演示的是 Healix B 端健管智能体。
不是旁边挂个聊天框，而是机构工作台的主入口：健管师每天先看今天该处理谁，再在对话里完成建议、方案、单据录入——AI 起草，人确认。

记住一句话

看谁优先 → 判怎么做 → AI 出草稿 → 人确认落库

第 0 幕 · 架构一页纸

只讲 60–90 秒

约 1 分钟 · 建立信任，不是主角

口播（可照念）

Healix 是医疗机构健康管理 SaaS：C 端患者、B 端健管、Ops 运维；数据按租户隔离，机构是工作边界。

B 端主入口是智能驾驶舱：左「今天该处理谁」，中「智能体对话」，右「患者上下文」。

AI（建议 / 方案 / OCR）挂在对话上；先进草稿或预填，健管师确认后才落库——模型不直接改业务数据。

底座是档案、任务、随访、报告；AI 加速起草，人不下环。

接下来进系统，把闭环跑通。

画板

租户 / 机构
  └── B 健管工作台（驾驶舱）
          ├── 今日优先（人）
          ├── 智能体对话（建议 / 方案 / OCR / 动作）
          └── 焦点快照 + 待确认草稿
      ↘ 人确认 → 业务库

讲

  1. 三角色 C / B / Ops
  2. 多租户 → 机构 → 患者
  3. 人在环：LLM 不直写库

不讲（除非追问）

  1. Spring 模块 / 包结构
  2. 类图、ER 全表
  3. Prompt / 压测数据
第一幕 · 看

驾驶舱开场

约 2 分钟

操作

  1. 登录 → 选机构 → 进智能驾驶舱
  2. 指三栏：左「今日优先」/ 中对话 / 右「当前焦点」
  3. 展示今日机构简报
  4. （可选）点「今日建议」

口播

左边按人聚合今天该盯谁；中间智能体先开口；右边是点人之后的工作上下文。
健管师不用先在多个菜单之间找人。

第二幕 · 判

点人进上下文

约 2 分钟

操作

  1. 点左栏一位有待办的患者
  2. 指右栏：风险 / 依从 / 档案 / 待确认 / 待办
  3. 等自动建议，或点「患者建议」
  4. 指气泡分节可读（一、二、三…）

口播

点人 = 注入患者上下文。智能体结合档案和任务给可执行建议，不是空聊天。

第三幕 · 做

动作落到业务

约 2 分钟 · 有数据再演，稳优先

操作（择一）

  1. 点动作卡：创建随访 / 查看档案 / 打开报告
  2. 或侧栏工作台核对任务
  3. 若支持：站内提醒 → 对话回执

口播

对话里的按钮打到现有业务能力上；结果可回执、可追。
AI 不会偷偷写库或自动办结。

时间紧？

本幕可砍，直接进方案。

第四幕 · 主卖点

管理方案生成

约 4 分钟

操作

  1. 确认仍在患者焦点
  2. 点「生成方案」或说「请生成管理方案草稿」
  3. 展示活动轨迹 + 流式正文
  4. 进预览 / 右栏「待你确认」
  5. 强调：草稿 → 人审 → 再发布（演示到草稿即可）

口播

主卖点之一：面向健管师可读的方案结构，边生成边展示。
先进草稿箱，发布必须人过眼——可追责、可上线。

后端可插一句

SSE 流式；LLM 输出不直写业务表，确认接口才持久化。

第五幕 · 主卖点

单据 OCR

约 3 分钟

操作

  1. 点「单据录入」→ 上传检验单或用药单
  2. 展示识别卡：标本 / 采样时间 / 报告时间 / 明细
  3. 故意改一处 → 点「确认入库」
  4. （可选）到检验/用药页核对

口播

另一主卖点：单据 OCR。识别只预填，确认才落库——和方案同一原则：AI 加速，责任在人。

后端可插一句

字段按字典校验；对不齐的进忽略列表并提示。

收尾

三句话带走

约 30 秒

口播

1）驾驶舱是健管师主入口，对话驱动工作；
2）方案和 OCR 是 AI 主卖点，任务与档案是运营底座；
3）全程人审——能跑通基本业务，也守住责任边界。

当前阶段：基本业务闭环已可演示试用；后续重点是稳定性与识别质量，而不是再铺页面。

顺序

  1. 定位 + 架构一页纸 · 1.5 min

  3. 点患者 → 建议 · 1.5 min
  4. 生成方案到草稿 · 2 min
  5. 一张 OCR → 确认入库 · 1.5 min

常见问答

被问到怎么答

和 ChatGPT 有何不同？

接机构业务数据与动作，结果进现有系统，可审可追，有租户隔离。

模型挂了？

简报可降级；方案显式失败；OCR/业务办理尽量不绑死模型。

数据安全？

租户/机构隔离；写库需员工确认。（没落地的审计别夸大）

下一步？

试用反馈 → 稳会话/流式与识别质量 → 再扩运营回顾。
