## 建议演示顺序（约 20–25 分钟）

1. **周启明**：建档 → 首诊 → 方案，讲清业务闭环（减重 + 血压双线）。
2. **林晓萱**：对照病种标签 / 驾驶舱待办 / 抽屉交互；对技术同事可补 B / C 端与机构隔离。
3. **陈建国**（可选）：高血压专线、用药与限盐运动话术。
4. **赵雨桐**（可选）：纯减重 + 女性健康 / 过敏忌口；对照「不勾慢病线」时模块显隐。

## 备注

- 职业选项无「私企老板」：经营应酬场景优先 **销售 / 商务**；强调自营可选 **自由职业**。
- 「希望多久达到体重目标」为周期选项：1 个月 / 3 个月 / 6 个月 / 约 1 年 / 不着急先稳住（非选具体日期）。
- 四位手机号互不重复；若本地已占用，改末两位即可。
