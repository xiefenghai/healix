# 问卷 → 方案：结构化映射（阻力 / 红线 / 家族史）

| 项 | 内容 |
|---|---|
| 目的 | 把首诊采集事实以**结构化 JSON**喂给方案 LLM，并用**写死策略**落地，避免模型空喊 |
| 实现位置 | `CarePlanPromptContextSupport` + `CarePlanContextService` + `management-plan` / `followup-summary` Skill |
| 整理日期 | 2026-11-12 |

## 数据流

```mermaid
flowchart LR
  Q[问卷答案] --> A[档案 / 目标 / 指标表]
  A --> Ctx[CarePlanContext patientContext]
  Ctx --> Skill[management-plan Skill]
  Skill --> Draft[方案草稿]
  Draft --> Safety[CarePlanSafetyService]
```

## 1. 执行阻力 `barrierStrategies`

问卷字段：`goal.constraints`（多选）→ 目标表 `preferences.constraints`。

生成方案时写入：

- `patientContext.goals.preferences.barrierStrategies[]`
- 顶层 `patientContext.barrierStrategies[]`（同内容，便于模型扫到）

| code | label | 必须落地 |
|---|---|---|
| `SOCIAL` | 应酬多 | `dietNote`：应酬点清蒸鱼/白灼虾、少浓汤、茶代酒 |
| `TAKEOUT` | 经常外卖 | `dietNote`：清蒸白灼少油、主食杂粮；示例餐偏外卖可执行 |
| `HUNGRY` | 总是觉得饿 | `dietNote`：正餐蛋白蔬菜留足，勿极端缺口 |
| `FAMILY` | 家人不太支持 | `dietNote`：给家属一句可执行配合 |
| `NO_TIME` | 没时间运动 | `exerciseNote`：碎片活动 / 通勤多走 / 久坐起身 |

Skill 硬规则：命中项必须写入 `diet.notes` / 运动 / 执行标题；禁止只写「应酬多所以少喝酒」。

## 2. 安全红线 `safetyRedlines`

来源：基础档案 `psych` / `medical`（首诊写回）。

| code | 触发 | Prompt | Safety 硬校验 |
|---|---|---|---|
| `EATING_DISORDER` | `eatingDisorderHistory` = YES/UNSURE | 不设热量缺口；称重每周；禁忌写入 contraindications | 每日称重 / 激进减重文案 → **ERROR** |
| `JOINT_ISSUES` | `jointIssues` 非 NONE | 低冲击；避开部位 | 跑步/跳绳/负重/VIGOROUS → **ERROR** |
| `EXERCISE_RESTRICTION` | `exerciseRestriction` 非 NONE | 强度上限 LIGHT；禁忌原文 | 同上；禁忌为空 → **WARN** |

## 3. 家族史（已进 basicArchive 摘要）

| 字段 | 含义 |
|---|---|
| `familyHistoryStatus` / `StatusLabel` | none / has |
| `familyHistoryItems[]` | 亲属 + 病种码/中文 |
| `familyHistorySummary` | 如「父·早发心梗；母·糖尿病」 |
| `earlyCvFamilyHistory` | 一级亲属早发心血管相关 |
| `firstDegreeDiabetesFamilyHistory` | 一级亲属糖尿病 |

Skill：写入 `rationale` 与监测保守度；禁止据此下诊断。

## 4. 首诊案头总结 vs 方案

| 环节 | 作用 | UI |
|---|---|---|
| `followup-summary` | 生成方案前的健管师快照：风险/禁忌/诉求/下一步 | 已提交后默认收起为「案头快照」 |
| 方案 `summary` / `goalSummary` | 阶段方案正文 | 方案页主展示 |
| 方案 `rationale` | 仅健管师生成依据 | 默认收起；打印不铺总览依据 |

### 4.1 首诊辅路径时效（`intakeBrief`）

生成方案时会读最近已提交首诊，但**不等于永远有效**：

| 条件 | 行为 |
|---|---|
| 提交后 ≤ 90 天（`freshness=FRESH`） | `keyAnswers` / `aiSummary` / `highlights` 可作现行约束；可写 `highlightGuidance` |
| 提交后 > 90 天或无提交时间（`STALE`） | 上述字段挪入 `historicalReference`；**不**再触发称重周频/阻断减重等高亮副作用；现行事实以档案 / 目标 / 指标 / `safetyRedlines` 为准 |

常量：`CarePlanPromptContextSupport.INTAKE_FRESH_MAX_DAYS = 90`。

## 5. 必填与建档

| 字段 | 规则 |
|---|---|
| `metric.HEIGHT` / `WEIGHT` | 问卷 `REQUIRED` |
| `basic.presentIllness` / `allergy.status` | 问卷 `REQUIRED` |
| 建档身高 | 表单选填；对话可抽「身高170cm」写入指标 |
