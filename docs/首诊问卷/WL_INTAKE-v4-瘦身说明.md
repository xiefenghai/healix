# WL_INTAKE v4 瘦身说明

| 项 | 内容 |
|---|---|
| 基线 | v3 ≈ 151 题（含条件显隐） |
| v4 | ≈ 98 题 |
| 策略 | 对照 `management-plan` Skill 反向删/并；历史答卷仍可读 v1–v3 模块 |

## 硬保留

身高体重、过敏、运动限制/关节、进食障碍、核心诉求与执行阻力、孕哺状态。

## 主要删除（相对 v3）

- 基础：微信号、职业、婚姻
- 运营：随访渠道/频次、是否医嘱驱动、测量来源
- 冗余体测：臀围
- 极低频：早绝经、黑棘皮、激素升糖、眼底检查时间、历史最高血压、成年最重/最轻
- 生活方式细项：入睡/起床/睡眠质量备注、烟量烟龄被动吸、酒量酒种、饮水自报、进食速度、独居、记饮食史、运动强度/时长/器械/场地/久坐小时等
- 外卖频次（并入「谁做饭」+ `goal.constraints`）

## 主要合并

- 情绪进食：压力/心情两题 → 一题 `emotionalEating`
- 减重史：保留 triedBefore / failReasons / recentTrend
- 家庭支持：并入执行阻力 FAMILY

## 兼容

`catalog.latest("WL_INTAKE")` → **v4**；旧 `QuestionnaireResponse` 仍按答卷上的 version 展开对应模块。
