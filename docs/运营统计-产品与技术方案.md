# 运营统计 — 产品与技术方案

> 与驾驶舱（今日干活）、依从看板（患者红绿）、工作台（逐条办结）分工：本页做**回顾与对比**，不做实时待办。  
> grill 拍板见文末；P0 已落地 API + 侧栏页。

## 一句话定位

回答「这支健管团队这段时间干得怎样、卡在哪里、闭环质量如何」。患者侧结果（依从/激活）为 **P1**，不进 P0 叙事。

## 与现有入口分工

| 入口 | 时间感 | 问题 |
|------|--------|------|
| 智能驾驶舱 | 今天 | 下一个该谁 |
| 工作台 | 现在 | 这张单怎么关 |
| 依从性看板 | 今天/近期 | 谁红了 |
| **运营统计** | 近 30 天回顾 | 团队供给效能 |

## P0 产品口径（已拍板）

- **主用户**：机构负责人；一线可进菜单看「本人 vs 健管组均值」
- **排行**：仅 `TENANT_ADMIN` 或机构内某健管组**主责健管**可见；非薪酬核算
- **及时率**：关单日归属；分母仅含有 `due_at` 的 DONE
- **超期未结 / 净积压**：看**此刻** OPEN（与日期筛选无关）
- **默认区间**：近 30 天；最长 90 天
- **健管组筛选**：按**办理人**所属组（非患者当前组）
- **未分配超期**：进机构总积压；排行单独「未分配」行（有组筛时不展示）
- **取消/过期**：不进办结量/及时率
- **下钻**：深链工作台（`pool`/`status` query）
- **菜单位置**：组织管理 → 运营统计

### KPI 一行

办结量 · 及时率 · 超期未结 · 完成随访 · 报告发布

## API

前缀：`/api/b/v1/ops-stats`

| 方法 | 说明 |
|------|------|
| `GET /summary` | KPI + 小趋势 |
| `GET /tasks/series` | 按日办结/及时率 |
| `GET /tasks/by-type` | 类型结构 |
| `GET /tasks/by-staff` | 排行或 self+groupAvg |
| `GET /followups/summary` | 随访摘要 |

参数：`from` `to` `careTeamId?` `staffId?`（非管理岗 `staffId` 强制本人）

## 实现要点

- 包：`com.healix.core.opsstats`；Controller：`BOpsStatsController`
- P0 实时 SQL；索引：`(org_id, status, done_at)` 等（`SchemaEnsureRunner`）
- 前端：`OpsStatsView.vue`；菜单在 `WorkspaceLayout.vue`

## 分期

| 阶段 | 范围 |
|------|------|
| **P0** | 任务效能 + 随访完成 + 报告发布；总览/排行/类型；深链工作台 |
| **P1** | `ops_stats_daily` 日批；方案质量；依从/激活；跨机构 |
| **P2** | Agent/OCR；Ops；导出 |
