## 1. 现状

管家是一轮文字问答：`POST /api/c/v1/agent/chat`。`IntentRouter` 分意图，`PatientBizTools` 只读今日方案、用药、近 7 天指标、随访、已发布报告、饮食和运动。模型在 150 字内回答。答不上时把工具原文念出来。气泡下最多 3 个跳转按钮。

写入档案、对话里打卡、按已发布章节讲解、把一句话送进健康沟通，现在都没有。每天 09:00 和 20:00 的 `DAILY_HEALTH_TODO` 已经在提醒没做完的方案和用药，本方案不再加一条推送。

## 3. 确认卡

挂在当轮回复下面，和现有跳转按钮分开。

| 卡 | 患者看到 | 确认后 |
|---|---|---|
| 记录 | 「记一次家庭血压 165/98，时间是现在？今天已有 120/80。」场景可改 | `VitalService` 现有记指标。血压成对、带 `bpContext`。血糖带 `mealContext`。体重单位 kg |
| 打卡 | 「把『早餐后测血糖』记为已完成？」多项则先选 | 方案走 `CarePlanCheckinService.upsertByPatient`。用药走现有打卡。状态为完成 / 跳过 / 已服 / 没吃 |
| 短讯 | 可改的一整句 | `CareChatFacade` 发到主管机构会话 |
| 讲解 | 无写入。药和剂量问题在三期只给「去问健管师」 | 只跳转 |

说「测了」但没有数字，只出打卡卡。说了数字又能对上今日任务，记录卡和打卡卡分开确认。

激励、依从、异常待办都跟着现有写入接口走，不另加一套。

## 4. 分期

### 4.1 一期：确认后记指标

患者说「血压 165/98」「血糖 7.2」「体重 70」或「140 斤」，出记录卡。预设增加「记一下血压」「记一下血糖」「记一下体重」。现有只读问答保留。

打开管家的问候本期不改。不打卡，不讲解，不发短讯。

### 4.2 二期：今日进度和打卡

打开管家时按 G13 说今天的完成情况和剩余项。说法与首页今日任务、今日应服药一致，不另编任务。

患者说「血糖测了」「药吃了」「这项跳过」，出打卡卡。预设增加「今天还有什么要做」。

### 4.3 三期：讲已发布的方案和报告

方案只讲当前已发布版本里患者问到的那一块。报告章节用 C 端已有的名字：健管师寄语、下期关注、阶段建议、本期要点、目标进度、本期成就、执行情况、指标变化、随访与干预、检验 / 检查。数字只来自该节已发布内容。

预设增加「给我讲讲这份报告」。用药和剂量问题走 G16 的空输入框跳转。

### 4.4 四期：短讯

G16 的按钮换成短讯卡。患者改完句子再确认，最终句子进入健康沟通，患者在沟通记录里看得到。

## 5. 技术要点

沿用 `HealthAgentService`。结构化动作不交给模型自由发挥。

| 环节 | 做法 |
|---|---|
| 抽数 | 规则识别血压对、血糖、体重、斤、空腹 / 餐后、诊室 / 家庭、现在 / 刚才。对不上 G7–G9 就不出卡 |
| 确认卡 | 新表存卡：租户、患者、类型、结构化载荷、过期时间、状态。改场景或改短讯走更新接口，只允许改这两类字段。`POST /api/c/v1/agent/cards/{id}/confirm` 校验本人、未过期、未使用 |
| 回复 | `AgentChatResponse` 增加 `cards`。跳转按钮逻辑不变 |
| 打开问候 | 二期起，按人按日记「今日清单已说」「完成情况已说」。20:00 以上海日历为准 |
| 讲解 | 三期取已发布正文的指定节，模型只压缩这一节的句子，不能添加节里没有的数字和建议 |
| 短讯 | 四期确认后调用现有患者发消息。正文不再经过模型 |
| 安全 | 非讲解回复仍过 `SafetyValidator`，仍限 150 字。系统提示保持不做诊断、不处方、不编造 |
| 配额 | 开放问答仍走 `AI_PATIENT_AGENT`。规则出卡、规则问候不计模型调用 |

## 6. 验收

1. 「血压 165/98」出家庭自测卡；改成诊室再确认，档案里是诊室。取消后没有新指标。
2. 「血糖 7.2」记为随机；「空腹血糖 7.2」记为空腹。
3. 「140 斤」卡上是 70.0 kg。没说单位的 140 按 140 kg 出卡。卡上不能改这个数。
4. 「126」或「126 毫克」不出卡。收缩压高于 260 不出卡，也不产生指标异常待办。
5. 「早上血压 130/80」「昨天的体重」不出卡。
6. 今天已有 120/80 时，卡上写明再记一次。确认后是两条。
7. 「血压 165/98，体重 70 公斤」两张卡。只确认一张时，另一项不入库。
8. 确认写入后，偏高偏低的读数与首页手记一样可以合并进「指标异常」。机构看不到这句话的对话原文。
9. 模型关闭时，说「血压 165/98」仍然出卡。
10. 二期当天第一次打开，有应做项才说进度。没有应做项仍是原来的问候。20:00 前第二次打开不重复完成情况。不新发站内信。
11. 二期「药吃了」在有多种应服药时先选择。昨天的任务在对话里打不上。
12. 记了血糖不会自动把方案任务打成完成。
13. 三期提问报告时，没有已发布报告就不出现编造的小结。没问到的章节不讲。停药问题不回答，并给出进入健康沟通的按钮。
14. 四期确认后的句子出现在健康沟通。未确认的句子不出现。不因此新开待办。
15. 首页今日任务的打卡方式与升级前一致。
