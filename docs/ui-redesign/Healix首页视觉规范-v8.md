## 1. 设计方向

> **「诊室级的秩序感 × 有人在旁的陪伴感」** —— 用临床级的克制与可读性建立信任，用唯一一个人格化锚点（专属健管师）打破工具的冰冷。

**判断依据**：Healix 对 C 端的真实差异化是「每个慢病患者有专属健管师」，不是又一个指标工具。视觉必须让「人」占住首屏第一眼，否则产品主张与界面不符。目标人群（慢病中老年 + 家属）的核心诉求是可信与被照顾——用冷的秩序打底，用一个暖的焦点点睛。

### 五条设计原则

| # | 原则 | 具体含义 | 违反判定 |
|---|---|---|---|
| P1 | **一屏一焦点** | 首屏只允许 1 个最高视觉权重元素（健管师卡），其余降为秩序网格。层级靠**尺度 + 色彩 + 留白**建立，不靠加阴影 | 首屏出现 2 个同权重色块 |
| P2 | **色为信息，不为装饰** | teal=品牌/主行动/正常；橙=待办；红=异常；蓝=信息。禁止渐变色块铺底 | 出现"为了好看"的品牌色填充 |
| P3 | **临床级可读** | 正文 ≥13px；正文/链接对比度 ≥4.5:1；数值用 `tabular-nums`；小号 teal 文字一律用 teal-700 及以上 | 10px 承载语义文案 |
| P4 | **圆角成阶梯、阴影成阶梯** | 按信息容器层级分 3 档，一级卡以下优先 1px 边线而非阴影 | 全站只有一个 radius / 一个 shadow |
| P5 | **呼吸优先于描边** | 用间距与底色分组，模块间距 > 卡内间距，不靠分隔线填满 | 卡内出现多条水平分隔线 |

### 2.6 ⚠️ 落地红线（必读，否则全 App 视觉回归）

- `var(--hx-shadow)` 被 **34 个文件 / 51 处**引用，`var(--hx-bg)` 被 **32 个文件**引用（含 `App.vue:45` 全局外壳）。这两个变量在全局 `:root` **保持原值不动**。
- **纯新增令牌**（teal/中性色阶、字号字重、`--hx-elev-*`、`--hx-hairline`、`--hx-r-*`、`--hx-sp-*`、`--hx-dur-*`、`--hx-bg-flat`）全库无现存引用，可直接并入 `style.css` 的 `:root`，**零回归**。
- **首页层级升级全部写进 `HomeView.vue` 的 `<style scoped>`**：
  ```css
  .home .card { box-shadow: var(--hx-elev-2); }   /* 原 var(--hx-shadow) */
  .l1-card    { box-shadow: var(--hx-elev-3); }
  .screen     { background: var(--hx-bg-flat); }   /* 替代双层径向光斑 */
  ```
- **全站统一替换 `--hx-shadow` / `--hx-bg` 属独立立项**（需逐页视觉 QA），不夹带进首页改版。
- 全局工具类 `.hx-cat` / `.hx-ck` 本轮不改值（CarePlanView / SleepView 共用），首页差异用首页专属 modifier 或 scoped 覆盖。

## 3. 三级层级系统

| 层级 | 元素 | 圆角 | 底色 | 阴影 | 主尺度 |
|---|---|---|---|---|---|
| **L1** | 健管师焦点卡 | **28** | `teal-700` 实底（零渐变，仅左上 12% 白点柔光） | **`elev-3`** teal 染色 | 头像 **56px** |
| **L2** | 今日待办 / 今日记录 / 今日用药 | **20** | `#fff` | `elev-2` | 标题 17·800，数值 24–28·900 |
| **L3** | 速记入口 / record-tile / metric-tile | **12–14** | `n-50` 或 `#fff`+hairline | `elev-0/1` | 图标容器 36px，标签 11·700 |

**建立层级的三手段（缺一不可）**
1. **尺度对比**：L1 头像 56px ↔ L3 图标 36px ↔ L3 标签 11px，形成 5× 跨度。
2. **色彩对比**：全页**只有 L1 使用品牌深色填充**，L2 纯白、L3 浅灰——第一眼必然落在深块。
3. **留白层级**：L1→L2 间距 24（焦点后留白），L2 内部块间距 12。留白差就是层级差。

## 6. 反 AI slop 禁令（10 条）

| ❌ Don't | ✅ Do |
|---|---|
| emoji 当功能图标（🔥 / 🎯 / `✓` 字符） | 统一线性图标或 SVG，三档 16/20/24 |
| 左侧 4px 彩色 accent 竖条 | 整卡浅底 + 图标容器表达类别 |
| 双层 radial 光斑背景 | `--hx-bg-flat` 单段极浅线性；焦点靠局部单点光 |
| 全站复用同一 `--hx-shadow` | 3 级 elevation ladder，一级卡以下优先 hairline |
| 品牌色大面积渐变铺底 | 渐变仅限 ≤32px 高小元素；品牌面用 `teal-600` 实底或 `teal-50` 浅底 |
| 字重全上 900 | 900 仅 ≥18px 数字与问候名 |
| 999 胶囊泛滥 | 胶囊只用于徽章/主按钮/勾选 |
| 用纯灰块填满界面 | 灰底只承载内容分组，无内容处留白 |
| 10px 承载语义文案 | 语义文案下限 11px，正文 ≥13px |
| 为"高级"加装饰光/玻璃拟态 | 层级靠尺度+色彩+留白；玻璃仅保留顶栏/底栏 |

## 7. 可读性与触达区

- `.link` → `teal-700`（3.3:1 → **5.26:1**）；`.metric-label` / `.section-sub` → `n-700`（4.4:1 → **5.9:1**）；火苗熄灭态 → `n-700`（on `#fff` 5.57:1 / on `n-50` 5.30:1）
- 焦点卡陪伴语 `rgba(255,255,255,.86)` = 4.7:1，**不得再降透明度**
- `.act-btn` 统一 **32px 高 / min-width 56px**（原 26–30px，不满足 WCAG 2.5.5）
- `.todo-item` 整行可点（勾选视觉尺寸保留 22px）；metric tile 整块可点

## 8. 落地步骤

完整迁移指引见 `_phase4-vue-migration.md`（组件映射表 11 项 + 数据源缺口 + 6 步迁移顺序 + 回滚方案）。三个关键前置：

2. **全局令牌红线**（见 §2.6）——任何"顺手全局换 `--hx-shadow`"的改动都会导致其它页面回归。
