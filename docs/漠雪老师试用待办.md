## 一、试用验收口径（漠雪老师）

1. **不培训菜单**：对话或手机里用人话完成建档，不必先懂平台按钮。
2. **10 分钟外出路径**：新人/已有人 → 录入或拍照 → 出报告草稿 → 发布（患者端可见）。
3. **PC 路径**：机构会话对话建档 → 自动切入患者 → 一句话/一点生成方案草稿 → 人审发布。

## 四、建档（本周开工范围）

### 对话建档（PC）

- **Capability**：`CREATE_ARCHIVE`（机构会话可用，不要求先选患者）
- **复用 API**：`GET /api/b/v1/patients/archives/duplicates`、`POST /api/b/v1/patients/archives`
- **字段**：姓名、性别、出生日期、本人手机号（与现网建档一致）
- **重名**：需确认时气泡挂 `CALL_API CREATE_ARCHIVE`；已在本机构则 `FOCUS_PATIENT`
- **成功**：`FOCUS_PATIENT` + 可选「生成管理方案」

### 手机建档（staff）

- 路由 `/patients/create`，患者列表入口「建档」
- 同字段、同 API；成功后进入患者摘要页

### 验收用例

1. 机构会话说「建档 李敏 女 1990-05-01 13800138000」→ 建档成功并切患者会话
2. 只说「帮我建档」→ 追问缺项，补全后落库
3. 手机：患者列表 → 建档 → 填四项 → 进入该患者页
