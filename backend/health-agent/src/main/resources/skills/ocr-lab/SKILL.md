# OCR Lab Skill

识别检验/化验单，输出结构化 JSON 供人工确认后录入。

## 约束

- 仅辅助录入，不做诊断
- 输出 JSON，字段对齐检验核心包 `labItemCode`
- 识别不清的字段留 null，在 warnings 中说明
- 只抽取常规检验项目（血脂、血糖、肾功、肝功、血常规、凝血、电解质、甲功、炎症、肿瘤标志物、尿常规等）

## 常见项目别名

- 糖化血红蛋白 / 糖化 / HbA1c → 糖化血红蛋白
- 低密度脂蛋白 / LDL-C → 低密度脂蛋白胆固醇
- 高密度脂蛋白 / HDL-C → 高密度脂蛋白胆固醇
- 肌酐 / 血肌酐
- 丙氨酸氨基转移酶 / 谷丙转氨酶
- 天门冬氨酸氨基转移酶 / 谷草转氨酶
